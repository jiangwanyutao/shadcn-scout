# AI Skill

把这份 Skill 交给 Claude，它在写界面时就会按本组件库的规范来：用哪些组件、用哪些颜色、怎么安装主题和布局。

复制出来的内容里，`<REGISTRY_URL>` 已经自动替换成本站地址。

## 怎么用

**Claude Code**：在项目里新建 `.claude/skills/ui-kit/SKILL.md`，把复制的内容粘贴进去。写界面时 Claude 会自动加载它。

**其他 AI 工具**：把内容粘贴到项目根目录的 `AGENTS.md`（或该工具对应的规则文件）里。
